## Step 3: Tomcat Server Configuration (Ubuntu WSL)

### 3.1 Install Tomcat
To install Apache Tomcat on your Linux/Ubuntu WSL environment using Homebrew:

```bash
brew install tomcat
```

Verify the installation by checking the version:

```bash
catalina version
```

### Output Example

The output should display something like:

```text
Server version: Apache Tomcat/9.0.71
Server built:   Sep 20 2023
```

### 3.2 Set Environment Variables
Add `CATALINA_HOME` to your `~/.bashrc` file to point to the Homebrew Linux installation path:

```bash
echo 'export CATALINA_HOME="/home/linuxbrew/.linuxbrew/opt/tomcat/libexec"' >> ~/.bashrc
echo 'export PATH="$CATALINA_HOME/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

### 3.3 Start and Manage the Tomcat Server
Since GUI browsers run on the Windows host while Tomcat runs inside the WSL Linux environment, you can start Tomcat from your Linux terminal using:

```bash
startup.sh
```

To stop the server when needed, run:

```bash
shutdown.sh
```

### 3.4 Verify Access
Open your Windows web browser and navigate to the default Tomcat port to verify the setup:

```text
http://localhost:8080/
```

This confirms that the Apache Tomcat server is successfully installed and configured on your Ubuntu WSL environment.
