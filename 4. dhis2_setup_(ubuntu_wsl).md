## Step 4: DHIS2 Installation and Configuration (Ubuntu WSL)

### 4.1 Download and Deploy DHIS2
Download the stable DHIS2 WAR file from the official releases to your Linux environment:

```bash
curl -L -o dhis.war https://releases.dhis2.org/2.39/dhis.war
```

Move the WAR file to the Tomcat webapps directory:

```bash
mv dhis.war $CATALINA_HOME/webapps/
```

### 4.2 Configure DHIS2 Settings
Create the DHIS2 home directory and configuration file inside your Linux user home directory:

```bash
mkdir -p ~/dhis2_home
nano ~/dhis2_home/dhis.conf
```

Add the following configuration properties to `dhis.conf`:

```properties
# PostgreSQL Configuration
connection.url = jdbc:postgresql://localhost:5432/dhis2
connection.username = dhis
connection.password = dhis
connection.driver_class = org.postgresql.Driver
connection.dialect = org.hibernate.dialect.PostgreSQLDialect

# Database Connection Pooling
connection.pool.max_size = 80

# Encryption Password (Change to a strong and unique password)
encryption.password = StrongUniquePassword123

# Server Configuration
server.port = 8080

# External Directory for File Storage (using Linux home path)
system.external_dir = /home/linuxbrew/dhis2_config
```

### 4.3 Set DHIS2 Home Environment Variable
Export `DHIS2_HOME` in your `~/.bashrc` file so the application can locate its configuration directory:

```bash
echo 'export DHIS2_HOME="/home/linuxbrew/dhis2_home"' >> ~/.bashrc
source ~/.bashrc
```

*(Note: Ensure your `~/dhis2_home` files match the path specified in your shell profile.)*

### 4.4 Start and Access DHIS2
Start your Tomcat server from your Ubuntu WSL terminal:

```bash
startup.sh
```

Open your Windows web browser and navigate to the DHIS2 web app portal:

```text
http://localhost:8080/dhis
```
